# Prompt-writing checklist

The five prompts use one consistent voice: a 27-year-old Yale MBA student supervising Campus Customs—polished, practical, warm, and operationally direct. Each role still has a distinct responsibility. When revising these prompts in your own words, preserve the same safeguards: MCP-only facts, ticket scope, shop-date rules, vendor invoice blocking, human payment approval, no negative cash, outbound-cash-only accounting, no real communications, privacy, and bounded loops.
